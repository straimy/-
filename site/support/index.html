MY TICKETS

Мои обращения

LAUNCHER

Лаунчер не запускается

Linux: запусти gungloryonline-launcher в терминале и приложи вывод. Windows: приложи скрин ошибки и версию Windows.

GAME

Игра не стартует

Проверь Java 17, Minecraft 1.20.1 и Forge 47.4.10. Официальный лаунчер умеет проверить и восстановить игровые файлы.

ACCOUNT

Проблема со входом

Для GGO browser login повтори запрос из лаунчера и подтверди его на сайте. Не подтверждай device-flow, который ты не запускал.

SERVER

Не подключается сервер

Официальный клиент сам выбирает production endpoint. Если соединение не проходит, приложи время попытки и последние строки latest.log.

SECURITY

Нашёл уязвимость

Не публикуй рабочий эксплойт и не используй его против игроков. Создай тикет с категорией «Баг» и пометь тему словом SECURITY.

MODERATION

Обжалование

Укажи GGO-ник, примерное время события, режим и краткое описание. Не создавай новые аккаунты для обхода активного наказания.
