FAQ

Частые вопросы

Нужен Microsoft аккаунт?

Нет. Основная идентичность — GGO аккаунт. Microsoft/Minecraft можно привязать дополнительно.

Нужен установленный Minecraft?

Для основного пути — нет. Лаунчер готовит Runtime v1. Для стороннего лаунчера используй Client Pack.

Как устанавливается Resource Pack?

Лаунчер не вшивает RP в клиент. При подключении сервер показывает стандартное предложение Minecraft и загружает официальный ZIP с ggo.kvicloud.ru с проверкой SHA1. RP сейчас необязательный — от него можно отказаться.

Какие Linux поддерживаются?

AppImage x86-64, DEB для Ubuntu/Debian и RPM для Fedora/RHEL. На Arch и других desktop-системах используй AppImage.
