FAQ

BEFORE
YOU DROP.

Нужен Microsoft аккаунт?

Нет. Основная идентичность — GGO Account. Microsoft/Minecraft можно привязать дополнительно.

Нужен установленный Minecraft?

Для основного пути — нет. GGO Launcher сам готовит Runtime v1. Для стороннего лаунчера пока остаётся Client Pack.

Как работает вход на официальный сервер?

Нажимаешь PLAY ONLINE в GGO Launcher — клиент получает короткую одноразовую игровую сессию и подтверждает её на официальном сервере. Команды /login и /register в обычном online-пути не используются.

Как устанавливается Resource Pack?

Лаунчер пока не вшивает Resource Pack в клиент. При подключении сервер предлагает официальный ZIP с ggo.kvicloud.ru и проверкой SHA1. Этот этап будет дальше переводиться в единый GGO update-путь.

Какие Linux поддерживаются?

AppImage x86-64, DEB для Ubuntu/Debian и RPM для Fedora/RHEL. На Arch и других desktop-системах используй AppImage.
