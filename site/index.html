FAQ

Частые вопросы

Нужен ли установленный Minecraft?

Для основного пути — нет. Лаунчер сам готовит свой Runtime v1. Если хочешь использовать сторонний Minecraft-лаунчер, скачай Client Pack.

Ресурс-пак надо включать руками?

В нашем лаунчере нет: обязательный RP устанавливается и включается автоматически. В ручном Client Pack он уже лежит в нужной структуре.

Какая версия?

Minecraft 1.20.1, Forge 47.4.10, Java 17.

Есть Linux?

Да. Основной Linux-релиз — AppImage x86-64. Он рассчитан на распространённые современные дистрибутивы.
