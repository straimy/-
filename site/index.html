FAQ

Частые вопросы

Нужен ли установленный Minecraft?

Для основного пути — нет. Лаунчер сам готовит Runtime v1. Если хочешь использовать сторонний Minecraft-лаунчер, скачай Client Pack.

Ресурс-пак надо включать руками?

В нашем лаунчере нет: обязательный RP устанавливается и включается автоматически. В ручном Client Pack он уже лежит в resourcepacks/, его нужно включить в настройках Minecraft.

Какая версия?

Minecraft 1.20.1, Forge 47.4.10, Java 17.

Какие Linux поддерживаются?

Есть универсальный AppImage x86-64, DEB для Ubuntu/Debian и RPM для Fedora/RHEL-совместимых систем. На Arch и других desktop-дистрибутивах используй AppImage.
