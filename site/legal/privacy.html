Политика конфиденциальности

Последнее обновление: 20.08.2026 · версия 1.0 Beta

Эта Политика описывает, какие данные использует GunGloryOnline при работе сайта, аккаунтной системы, лаунчера и игровых серверов, зачем они нужны и как защищаются.

1. Какие данные могут обрабатываться

Аккаунт

Ник/логин, внутренний GGO ID, выбранный язык, регион и страна профиля, источник скина, дата создания аккаунта.

Данные входа

Пароль используется только для проверки подлинности. В базе не хранится исходный пароль: сохраняются соль и криптографический результат функции scrypt. Для сессий используются случайные access/refresh токены; на сервере хранятся их SHA256-хэши.

Device login

При входе лаунчера через браузер временно обрабатываются идентификатор запроса устройства, installation ID, PKCE challenge, время создания и статус подтверждения. Незавершённые device-flow имеют короткий срок жизни и удаляются после истечения.

Игровые и технические данные

Сервер может обрабатывать ник, GGO ID, игровые события, наказания, технические логи, IP-адрес, время подключения, версию клиента и диагностические данные, необходимые для безопасности, античита, устранения ошибок и поддержки.

Связанные аккаунты

Если пользователь добровольно привязывает Microsoft/Minecraft, могут обрабатываться публичные идентификаторы Minecraft и данные, необходимые для подтверждения принадлежности аккаунта. Пароль Microsoft GunGloryOnline не получает.

2. Для чего используются данные

Данные используются для регистрации и входа, сохранения игрового профиля, авторизации лаунчера, безопасности аккаунтов, работы серверов, синхронизации настроек, поддержки пользователей, предотвращения злоупотреблений и развития сервиса.

3. Cookies и локальные данные

Сайт использует HttpOnly session-cookie для авторизации. Cookie помечается SameSite=Lax, а при HTTPS — также Secure. Лаунчер хранит только те локальные настройки, которые нужны для его работы. Пароль пользователя не должен сохраняться в localStorage.

4. Передача третьим лицам

Мы не продаём персональные данные рекламодателям. Часть данных может технически обрабатываться инфраструктурными поставщиками, через которых работают VDS, DNS/CDN или внешняя авторизация Microsoft, только в объёме, необходимом для соответствующей функции.

5. Хранение

Сессионные access-токены имеют ограниченный срок жизни, refresh-токены — более длительный срок для повторной авторизации. Устаревшие токены и device-flow очищаются автоматически. Аккаунтные и игровые данные могут храниться дольше, пока существует аккаунт или пока данные нужны для безопасности и разрешения споров.

6. Безопасность

Используются хэширование паролей через scrypt, случайные токены, хранение только хэшей токенов на сервере, PKCE для browser/device login, HttpOnly cookies и HTTPS после выпуска сертификата. Ни одна система не может гарантировать абсолютную безопасность, поэтому при обнаружении уязвимости следует сообщить через поддержку и не использовать её против пользователей.

7. Права пользователя

В зависимости от применимого законодательства пользователь может иметь право запросить доступ, исправление или удаление своих данных, а также ограничение определённой обработки. Для этого используй поддержку. Для подтверждения запроса может потребоваться доказать владение аккаунтом.

8. Данные несовершеннолетних

Если местное законодательство требует согласия родителя или законного представителя для использования онлайн-сервиса, пользователь должен получить такое согласие до регистрации.

9. Международная инфраструктура

Пользователи могут подключаться из разных стран, а серверная инфраструктура может находиться в другой стране. Это означает, что технические данные могут передаваться между странами в пределах, необходимых для работы сервиса.

10. Обновления политики

Политика может изменяться вместе с архитектурой проекта. Дата актуальной редакции всегда указывается вверху страницы.

11. Контакт

По вопросам конфиденциальности используй раздел поддержки GunGloryOnline. Никогда не отправляй свой пароль или полный session token.
